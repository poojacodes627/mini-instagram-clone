Mini Instagram Clone 🚀

A modern social media style web application inspired by Instagram, built using HTML, CSS, JavaScript, Node.js, and Express.js.

✨ Features

- Create Posts
- Delete Posts
- Like System ❤️
- Comment Section 💬
- Save & Share Options 🔖
- Dynamic Feed UI
- Frontend + Backend Integration
- REST API Based Project

🛠 Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js

▶️ How to Run

Install Dependencies

npm install

Start Backend Server

cd backend
node server.js

Open Frontend

Open frontend/index.html using Live Server.
